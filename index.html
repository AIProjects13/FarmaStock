Base de caja

Este es el punto de partida del conteo. A partir de la fecha que elijas, el sistema suma las ventas en efectivo y resta los gastos. Cuando hagas un cierre de caja, el conteo vuelve a arrancar desde el saldo que quede ese día.

Si ponés una fecha posterior al último cierre, esta base manda y todo lo anterior deja de contar. Sirve para volver a arrancar limpio después de cargar inventario.

Si elegís hoy, el conteo arranca en este mismo instante: todo lo registrado antes de ahorita deja de contar.
